# 观看小助手

观看小助手是一个 Chrome 和 Edge 浏览器扩展，按你的偏好把不想看的视频从网页列表中隐藏，并从后面的页面补上符合条件的视频。

它在 MissAV 上提供全部功能：按标签、分类和女优人数筛选，并在封面上显示女优姓名。在其他采用同类视频列表的网站上，可以按标签筛选和补位；分类和女优功能只在 MissAV 上可用。

## 功能

**按标签隐藏。** 卡片上带有无码、中文字幕或其他字幕标记的视频可以分别隐藏；也可以隐藏没有任何标签的视频。

**按分类筛选。** “只显示这些分类”留空时不限制，选择后视频至少符合其中一项才显示；“隐藏这些分类”命中任意一项即隐藏，并且优先于“只显示”。同一分类在网站上的不同写法会合并为一项，常用的分类排在前面。“4 小时以上”按视频时长判断。

**按女优人数隐藏。** 女优人数超过设定上限的视频会被隐藏。同一演员的不同艺名合并计数；无法确认身份的名字不计入人数，所以不会因为一个陌生的名字多算一人。

**封面显示姓名。** 封面左上角显示前三位女优的名字，过长时省略。

**补位和连续滚动。** 一页被筛掉一部分时，扩展会从后续页面取符合条件的视频补齐，首页各栏也会补齐。连续查找若干页仍不够一页时会停下并提示，点击提示可以继续查找。开启“连续滚动”后，接近页面底部会自动加载并筛选下一页。

筛选适用于首页、搜索结果、演员页和分类页等视频列表，播放页保持原样。首页可以单独关闭，顶部开关可以暂停全部筛选。

## 默认设置

首次安装后：

- 隐藏带无码标记的视频。
- 隐藏伪娘、变性和异装相关的分类。
- 女优超过 3 人时隐藏。
- 封面显示女优姓名。
- 首页生效，连续滚动关闭。

点击“恢复默认”会回到以上设置；10 秒内可以点击“撤销”找回之前的设置。

## 安装

1. 下载并解压扩展文件，保留整个文件夹。
2. 在 Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的文件夹。
5. 刷新已经打开的网页。

安装后可以把“观看小助手”固定到工具栏，点击图标打开设置。

## 更新

用新版本的文件覆盖原来的文件夹，然后在扩展管理页点击这个扩展的“重新加载”，再刷新网页。设置会保留。

浏览器按文件夹位置识别解压安装的扩展。从另一个文件夹加载会被当作一个新扩展，原来的设置不会带过去。

## 隐私与权限

设置、分类列表和视频资料缓存只保存在这台电脑的浏览器里，不随浏览器账号同步。旧版本曾把设置同步到浏览器账号；升级后设置会自动转到本机，账号里留下的旧副本可以在设置面板中删除。

在 MissAV 上使用分类条件或女优功能时，扩展会把当前列表中的视频编号发给 MissAV 使用的分类服务，查询分类、时长和女优名单。查到的资料缓存一周。扩展不发送账号信息、浏览记录或本地文件，也不下载视频。

为了识别各网站的视频列表，扩展会在你打开的网页上运行，浏览器因此会提示它可以访问所有网站。你可以在扩展管理页把网站访问权限限制为自己使用的网站。

女优艺名的对应关系来自随扩展附带的名录，来源和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
