# MissAV 观看小助手

MissAV 观看小助手是一个用于 MissAV 的浏览器扩展，支持 Chrome 和 Edge。它会按你的偏好，把不想看的影片从网页列表中隐藏，减少逐个翻找和跳过的麻烦。

你可以按标签和分类设置筛选条件，保留感兴趣的内容，排除不想看的内容。设置一次后，浏览、搜索和翻页时都会自动筛选。

## 它能帮你做什么

**把不想看的内容直接隐藏。** 设置排除条件后，符合条件的影片会从列表中消失，不再需要你逐个跳过。

**只浏览自己感兴趣的分类。** 在“只显示这些分类”中选择喜欢的分类，就能缩小浏览范围；再用“隐藏这些分类”排除不喜欢的内容。同时命中两边条件的影片会被隐藏。

**筛选后继续补充内容。** 一页影片被筛掉大半时，扩展会自动从后续页面寻找符合条件的影片补进来，减少“这一页没几条，还得继续翻”的情况。首页各栏也会自动补充。

**一直向下看，少点几次下一页。** 开启“连续滚动”后，接近页面底部会自动加载下一页，并筛选新内容。

以上功能适用于 MissAV 首页、搜索结果、演员页和分类页等视频列表。可以单独关闭首页筛选，也可以随时暂停全部筛选。播放详情页保持原样。

## 安装

1. 下载并解压扩展文件，保留整个文件夹。
2. 在 Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的文件夹。
5. 允许扩展访问 MissAV，然后刷新网站页面。

安装后可将“观看小助手”固定到浏览器工具栏，点击桃红色眼睛图标打开设置。

## 使用

打开 MissAV，点击扩展图标，按自己的偏好调整筛选条件：

- **隐藏标签**：勾选不想看到的标签，带有这些标签的影片会被隐藏。
- **只显示这些分类**：留空时不限制分类；选择后，视频至少符合其中一项才会显示。
- **隐藏这些分类**：符合其中任意一项就会隐藏。隐藏条件优先，即使同时符合“只显示”的条件也会隐藏。
- **首页生效**：关闭后首页恢复原有内容，其他列表页继续筛选。
- **连续滚动**：开启后向下滚动即可继续浏览；关闭后使用网站原有分页。

分类可以搜索添加，点击已选分类上的 `×` 即可移除。顶部开关可暂停全部筛选，“恢复默认”可重置设置。

## 隐私与权限

筛选设置和分类缓存保存在浏览器内。分类筛选会向 MissAV 使用的分类服务查询相关视频编号，不发送账号信息或本地文件。

浏览器可能提示扩展可访问 HTTP/HTTPS 网站；你可以在扩展管理页将访问权限限制为自己使用的 MissAV 地址。扩展不下载视频。
