# MissAV 观看小助手

MissAV 观看小助手是一个用于 MissAV 的浏览器扩展，支持 Chrome 和 Edge。它会按你的偏好，把不想看的影片从网页列表中隐藏，减少逐个翻找和跳过的麻烦。

你可以按标签和分类设置筛选条件，保留感兴趣的内容，排除不想看的内容。设置一次后，浏览、搜索和翻页时都会自动筛选。

## 它能帮你做什么

**把不想看的内容直接隐藏。** 设置排除条件后，符合条件的影片会从列表中消失，不再需要你逐个跳过。

**只浏览自己感兴趣的分类。** 在“只显示这些分类”中选择喜欢的分类，就能缩小浏览范围；再用“隐藏这些分类”排除不喜欢的内容。同时命中两边条件的影片会被隐藏。

**筛选后继续补充内容。** 一页影片被筛掉大半时，扩展会自动从后续页面寻找符合条件的影片补进来，减少“这一页没几条，还得继续翻”的情况。首页各栏也会自动补充。

**一直向下看，少点几次下一页。** 开启“连续滚动”后，接近页面底部会自动加载下一页，并筛选新内容。

以上功能适用于 MissAV 首页、搜索结果、演员页和分类页等视频列表。可以单独关闭首页筛选，也可以随时暂停全部筛选。播放详情页保持原样。

## 安装

1. 下载并解压扩展文件，保留整个文件夹。
2. 在 Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的文件夹。
5. 允许扩展访问 MissAV，然后刷新网站页面。

安装后可将“观看小助手”固定到浏览器工具栏，点击桃红色眼睛图标打开设置。

## 使用

打开 MissAV，点击扩展图标，按自己的偏好调整筛选条件：

- **隐藏标签**：勾选不想看到的标签，带有这些标签的影片会被隐藏。
- **只显示这些分类**：留空时不限制分类；选择后，视频至少符合其中一项才会显示。
- **隐藏这些分类**：符合其中任意一项就会隐藏。隐藏条件优先，即使同时符合“只显示”的条件也会隐藏。
- **首页生效**：关闭后首页恢复原有内容，其他列表页继续筛选。
- **连续滚动**：开启后向下滚动即可继续浏览；关闭后使用网站原有分页。

分类可以搜索添加，点击已选分类上的 `×` 即可移除。顶部开关可暂停全部筛选，“恢复默认”可重置设置。

## 偏好存储与迁移

- **新设置默认仅本机保存**：使用 `chrome.storage.local`，不会向 `chrome.storage.sync` 写入筛选偏好。
- **同步需要主动选择**：在“偏好存储与隐私”中选择现有同步副本，或确认上传当前设置。标签、包含/排除分类、人数阈值及其他筛选开关都会进入浏览器同步存储。浏览器同步开启时，这些偏好可跨同账号设备同步；本扩展不判断你的账号是否已经开启浏览器同步。
- **旧版设置不会静默迁移**：若发现旧的同步偏好且本机尚未选择存储位置，页面继续使用旧偏好，弹窗暂不允许编辑，直到你选择“仅本机”或继续同步。读取与检测不会修改或删除任一副本。
- **已有副本与覆盖是不同操作**：“使用现有副本”保留存储中的两份数据，改用所选副本；“保存当前设置”会替换目标副本，操作前再次说明并确认。当前界面中的设置也可能包括保存失败后尚未落盘的更改。
- **切换到本机不会删除旧同步副本**：其他设备的选择不变，本机原有副本在切到同步后也会保留。扩展目前没有删除同步副本的按钮；关闭同步、切换存储位置或清除元数据缓存都不代表云端副本已被删除。

更改会短暂合并后自动保存。请保持弹窗打开，直到显示“已保存”；只有浏览器确认写入成功后才显示该提示。失败时仍显示“未保存”，网页继续使用上次成功保存的设置，可重试、减少规则，或将当前设置改存本机。初次读取失败时编辑被禁用，避免用默认值覆盖未知的已存设置。“重新读取”会在确认后放弃未保存的更改。

“恢复默认”只更新当前选定存储位置的偏好；同步模式下会同步这些默认值，不改变存储位置，也不清除缓存或另一份保留副本。

## 隐私、缓存与权限

元数据缓存、已发现分类及缓存计数只保存在 `chrome.storage.local`。缓存键、元数据和查询时间可能反映查询过的项目；自动补位会预查询，因此它不是精确观看历史。

- 元数据有效期为 **7 天**，最多保留 **5000 项**；过期或缺少有效时间的记录不会用于筛选，离线时也不使用过期记录兜底
- 有效期控制能否复用缓存，并不保证在第 7 天自动删除磁盘数据；再次查询会尝试刷新，未查询的过期记录可能保留至清除或容量淘汰
- 弹窗中的“清除元数据缓存”同时移除缓存、已发现分类与计数，不改变筛选偏好；之后的页面查询可以重新生成缓存

分类筛选会向 MissAV 使用的分类服务查询相关视频编号，不发送账号信息或本地文件。

浏览器可能提示扩展可访问 HTTP/HTTPS 网站；你可以在扩展管理页将访问权限限制为自己使用的 MissAV 地址。扩展不下载视频。
